# SCRAP REBORN 3D — 0.1.2

Сборка в разработке. Модели, анимации и кампания ещё не прошли полную приёмку.

Одиночная 3D-глава для Windows. Исследуйте пять секторов комплекса, повреждайте реальные узлы противников, снимайте уцелевшие компоненты и собирайте свой корпус на ремонтных станциях.

## Запуск

Запустите `ScrapReborn-0.1.2.exe`. Для запуска исходников используйте `D:\GameDev\bin\godot.cmd --path D:\GameDev\Projects\ScrapReborn3D`.

Новая игра начинает кампанию. Испытательный полигон открывает склад полного каталога; его содержимое не считается переносимым грузом, пока предмет не взят. В полигоне сохранение кампании отключено.

## Важные правила

- Обе руки — разные узлы. Поломка руки отключает её оружие.
- Питание и CPU — жизненно важные компоненты. Потеря ног ограничивает передвижение.
- Целый торс закрывает внутренние узлы. Вскрытый корпус открывает процессор, питание и охлаждение.
- Разрушение не случайно. Перебор урона, тип атаки и выбранный режим определяют сохранность детали.
- Снятая деталь сохраняет точную прочность и уникальный идентификатор.
- Аккуратный демонтаж сохраняет состояние. Другие способы показывают точную потерю прочности.
- Ремонт стоит лом. Критически разрушенные компоненты не восстанавливаются.
- В мастерской доступны склад и сравнение установки. Переносимая добыча увеличивает массу, склад — нет.
- Ручное оружие требует совместимого манипулятора. Дроновые компоненты требуют адаптер.
- Откройте техническое хранилище в боковой комнате каждого сектора, чтобы получить фиксированный набор оборудования и программ.
- Перед выходом восстановите три контура и нейтрализуйте оставшиеся боевые системы. Обратный маршрут доступен у входа следующего сектора.

## Локальные данные

Сохранения и настройки: `D:\GameDev\Projects\ScrapReborn3D\.userdata`. Основное сохранение имеет резервную копию. Повреждённые файлы сохраняются отдельно при восстановлении. Тестовые сохранения изолированы от пользовательской кампании.

## Сборка и проверка

Инструменты: Godot 4.7.2 Compatibility и Blender 5.2.3 LTS. `tools/build.ps1` импортирует ресурсы и экспортирует Windows x86_64.

Проверки: `tests/simulation_test.gd`, `tests/player_journey.gd`, `tests/benchmark.gd`, `tests/soak.gd`. Встроенный режим `-- --acceptance` проверяет интеграцию кампании в экспортированном приложении. Он использует автоматизированные действия и не подтверждает длительность обычного прохождения.

Состояние проверки и известные ограничения: `docs/STATUS.md` в исходном проекте.
